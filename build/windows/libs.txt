# Format:
#   name|version|type|url-or-source-list
#
# Notes:
#   - Lines starting with '#' are comments.
#   - Empty lines are ignored.
#   - 'type' must match one of the build handlers in build_3rdparty.ps1.
#   - Multiple sources may be separated with ';' and are tried in order.
#   - A source may be an https URL or a local archive path.
#
# Example with fallback/local cache:
#   mysql-server|8.0.42|mysql|https://dev.mysql.com/get/Downloads/MySQL-8.0/mysql-8.0.42.tar.gz;D:\cache\mysql-8.0.42.tar.gz
#
# MySQL downloads use the cdn.mysql.com archive first: dev.mysql.com answers
# 403 to the PowerShell and BITS user agents, and the archive URL stays valid
# after a newer release replaces the version on the download page.

# tarball on snapshot.debian.org (cairo_1.18.0.orig.tar.xz, same SHA256).
# The archive is named after the first source, so the fallback URL needs
# no file name.
